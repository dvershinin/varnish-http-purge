Proxy Cache Purge
==================

## Description

This is the development repository for the Proxy Cache Purge plugin (formerly known as Varnish HTTP Purge).

You should install the plugin from the [WordPress.org Repository](https://wordpress.org/plugins/varnish-http-purge/). The `trunk` branch mirrors the stable release; active development happens on dedicated release and feature branches.

Proxy Cache Purge is currently maintained by [GetPageSpeed](https://www.getpagespeed.com/), focusing on high-performance NGINX and proxy caching setups and integrating well with both open-source Varnish and the commercial [NGINX Extras](https://nginx-extras.getpagespeed.com/) collection, including the [NGINX cache-purge module](https://nginx-extras.getpagespeed.com/modules/cache-purge/).
